### 📘 Overview

**Fractal Causality v4.0** explores the emergence of self-similar, fractal dynamics within synthetic neural systems.

Using a Wilson–Cowan excitatory-inhibitory model implemented on a 5 000-node hybrid small-world / scale-free graph, the project investigates how population-level interactions can spontaneously reproduce the statistical signatures of real EEG activity.

This version (v4.0.1) documents the **Day-2 PASS milestone**, confirming **3 / 5 matching metrics**:
- Spectral scaling α ≈ 0.97  
- Autocorrelation τ ≈ 412 ms  
- Hurst exponent H ≈ 0.75  

These findings provide empirical support for **Core Hypothesis 1 — Fractal Signature Reproduction**.
